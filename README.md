### 0.
Install Alfred

### 1.
Go to correct directory
```bash
cd ~/Library/Application\ Support/Alfred/Alfred.alfredpreferences 
```

### 2.
Delete empty workflows
```bash
rm -rf workflows
```

### 3.
Clone repo
```bash
git clone https://github.com/OlofDaniel/workflows.git ~/Library/Application\ Support/Alfred/Alfred.alfredpreferences
```
